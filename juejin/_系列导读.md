# 手写一个 Vue3 内核 · 系列导读

> 一个月的篇幅，从零把 Vue3 的响应式、渲染器、编译器、再到打包——全部自己写一遍。
> 与其零散地看源码逐行注释，不如跟着**亲手重写**的节奏，把「为什么长这样」问到底。

## 这个系列讲了什么

Vue 3 内核 = 三块硬骨头 + 一圈配角：

```
响应式（Proxy + track/trigger）      ← 阅读顺序第一步
渲染器（vnode → 真实 DOM，keyed diff）
编译器（template → render 函数）
配角：组件实例 / 调度器 / Options API / Transition / KeepAlive / patchFlag·block·hoist
```

每篇的写法一致：**从你写过的日常场景开场，先讲设计动机，再看关键实现，把这条路上真正踩过的坑摊开，末尾用「三步走复盘」收束**。
代码都是节选（能说明问题的最小片段，通常不超过十五行），完整实现在一个可 fork 的本地工程里随文复刻。

## 适合谁 / 怎么读

- 会写 Vue3（组合式 API 顺手的程度），想知道 `ref`、`nextTick`、`keyed diff` 背后是什么；
- **按顺序读**：**00 全景 → 01 响应式 → 02 渲染器 → 03 编译器** 是最小闭环；04 补全、05 打包为进阶；
- 每篇结尾还有「自查三问」，答案都埋在正文里——能不回看、用自己的话答出来，就算这一篇到手了。

## 配套实现

每篇涉及的核心代码，都来自一个从零手写的 **mini-vue 工程**（TypeScript，208 个测试全绿）。
装好 `node + pnpm` 后：

```bash
pnpm test          # 复现文中全部行为的测试
pnpm dev:showcase  # 跑起来看（一个自研引擎渲染的展示页）
pnpm build         # 参考官方脚手架打包
```
