# mini-vue — 项目概览

> 从零手写自己的 **Vue3 内核**，把原理吃到源码级别。

## 为什么做这个项目

学习「原理 + 源码」最可靠的办法，是照着真源码把框架重写一遍：
每个阶段先**跑真 Vue 的测试锚定行为**，再**读真源码**，然后**用简化的 mini 实现复刻行为**，最后用测试/demo 验证，并写中文笔记沉淀。

## 项目目标（终态）

自己完成 **Vue3 内核**（响应式 → 渲染器/组件 → 编译器 → 补全），并用一个不依赖任何第三方框架的展示 app 收官：

```
"<div>{{ n }}</div>"
   → compiler（parse→transform→codegen，patchFlag/block/hoist）
   → render 函数（with(_ctx)）
   → instance.update = effect(fn, { scheduler })
   → renderer patch（keyed diff / block 快速路径）→ DOM
```

全部代码自研、有测试、能 `pnpm build` 打包成可发布的产物。

> 注：**mini-vue-router / mini-pinia 经用户确认取消，不做了**（2026-09-20）——
> 项目范围收敛为「vue 内核本身」；阶段文档里若提及它们，仅作「生态里谁是 effectScope/markRaw 的消费者」教学举例，
> 不代表本仓库要构建它们。

## 四个约定

| 维度 | 决策 |
|---|---|
| 语言 | **TypeScript**（与真源码类型系统对齐） |
| 编译器 | **完整三件套**：reactivity + runtime(core+dom) + compiler-core（template → render 闭环） |
| 推进方式 | **分阶段**：每阶段 = 真源码解读 + mini 实现 + 测试/demo + 中文文档；review 通过才进下一阶段 |
| 集成 | **自洽 kernal**：所有代码跑自己写的 reactity/runtime/compiler 上；不依赖真 Vue |

## 仓库结构

```
packages/
  shared/        基础工具（类型判断、常量、ShapeFlags/PatchFlags）
  reactivity/    响应式（阶段 1-2）
  runtime-core/  运行时核心（阶段 3-4、7）
  runtime-dom/   DOM 平台层（阶段 3-6）
  compiler-core/ 模板编译器（阶段 5、7-3）
  compiler-dom/  DOM 编译扩展（阶段 5-6）
  vue/           聚合入口 @mini-vue/vue
examples/
  playground/    纯 h() 手写 demo
  showcase/      展示页：模板驱动，全能力面面观
docs/            每阶段中文学习笔记 + 阅读地图（01-07 / 10 / 14）
third_party/     真源码副本（vue v3.5.43），仅供本地阅读
scripts/         构建驱动（build.js）等工具
```

## 依赖方向铁律（单向）

```
shared → { reactivity, compiler-core }
reactivity+shared → runtime-core
runtime-core+… → runtime-dom
compiler-core+… → compiler-dom
(以上) → @mini-vue/vue
```

不允许反向 import：任何上层包不得依赖下层。

## 常用命令

```bash
pnpm test            # 208 个测试
pnpm dev:playground  # h() 手写 demo
pnpm dev:showcase    # 展示页（模板驱动）
pnpm build           # 打包：每包 dist/{esm-bundler.js,cjs,d.ts}，vue 另有 global.js
pnpm build:prod      # __DEV__=false + 压缩（*.prod.*）
```
