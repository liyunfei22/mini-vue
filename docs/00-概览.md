# mini-vue 全家桶 — 项目概览

> 从零手写自己的 **Vue3 / Vue Router / Pinia**，把原理吃到源码级别。

## 为什么做这个项目

学习「原理 + 源码」最可靠的办法，是照着真源码把框架重写一遍：
每个阶段先**跑真 Vue 的测试锚定行为**，再**读真源码**，然后**用简化的 mini 实现复刻行为**，最后用测试/demo 验证，并写中文笔记沉淀。

## 项目目标（终态）

一条 **SPA** 里同时做到三者自洽运行：

```
mini-vue（响应式 + 运行时 + 编译器） ← 承载
  ├── mini-vue-router（路由：当前路由、嵌套、参数、守卫）
  └── mini-pinia（全局状态：store、getters、actions）
```

即 capstone 阶段：一个「mini 商店」应用，全部跑在我们自己写的代码上。

## 四个约定

| 维度 | 决策 |
|---|---|
| 语言 | **TypeScript**（与真源码类型系统对齐） |
| 编译器 | **完整三件套**：reactivity + runtime(core+dom) + compiler-core（template → render 闭环） |
| 推进方式 | **分阶段**：每阶段 = 真源码解读 + mini 实现 + 测试/demo + 中文文档；用户 review 通过才进下一阶段 |
| 集成 | **全家桶自洽**：mini-router / mini-pinia 跑在 mini-vue 上，不用 npm vue |

## 仓库结构

```
packages/
  shared/        基础工具（类型判断、常量、ShapeFlags）
  reactivity/    响应式（阶段 1-2）
  runtime-core/  运行时核心（阶段 3-4）
  runtime-dom/   DOM 平台层（阶段 3-6）
  compiler-core/ 模板编译器（阶段 5-6）
  compiler-dom/  DOM 编译扩展（阶段 5-6）
  vue/           聚合入口 @mini-vue/vue
  vue-router/    mini 路由（阶段 7）
  pinia/         mini 状态管理（阶段 8）
  parity/        与真 vue/router/pinia 的行为对拍
  examples/      playground（手写 demo）+ capstone（最终 SPA）
docs/            每阶段中文学习笔记 + 阅读地图 + 对拍清单
third_party/     真源码副本（vue v3.5.43 等），仅供本地阅读
scripts/         自包含性检查等工具
```

## 依赖方向（单向铁律）

```
shared → { reactivity, compiler-core }
reactivity+shared → runtime-core
runtime-core+… → runtime-dom
compiler-core+… → compiler-dom
(以上) → vue → vue-router
vue+reactivity → pinia
```
