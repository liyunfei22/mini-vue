# 实现 Vue 3 内核 · 系列导读

> 本系列跟随一个从零实现的 mini-vue 工程，逐个子系统地重写 Vue 3 的内核：响应式系统、渲染器与组件、模板编译器、内核补全、构建流水线。每篇讲清三件事：这个子系统的设计动机、关键实现的逐点分析、以及与官方实现的差异清单。

## 系列内容

| # | 主题 | 覆盖 |
|---|---|---|
| 00 | 权衡与整体架构 | 命令式与声明式、运行时与编译时的分工；虚拟 DOM 的定位；七个包的职责与一次更新的完整数据流 |
| 01 | 响应式系统 | targetMap 与 track/trigger、副作用的依赖清理与嵌套、调度器、computed 的惰性与脏位、ref 容器、effectScope |
| 02 | 渲染器与组件 | vnode 协议与宿主操作注入、shapeFlag 与 patch 分发、组件实例（渲染副作用 + 调度队列）、keyed diff 与最长递增子序列、事件缓存 |
| 03 | 模板编译器 | parse 状态机、transform 双阶段与结构指令、codegen 与 `with(_ctx)` 取舍、compileToFunction 的运行时接线 |
| 04 | 内核补全 | Options API 与组合式 API 的共存、Transition/KeepAlive 与渲染器的协作、补丁标记/区块/静态提升三件套 |
| 05 | 构建与发布 | rollup 多格式产物、`__DEV__` 注入机制分析、exports 的 source 条件、类型声明两段式、工程陷阱 |

## 读法建议

- **按顺序读**。00–03 构成最小闭环：架构 → 响应式（何时重渲染）→ 渲染器（如何更新 DOM）→ 编译器（模板如何变成渲染函数）；04、05 为补全与工程化，可独立阅读但依赖前三篇的术语。
- 每篇结构一致：引言交代范围与前置，正文按子问题推进（问题 → 权衡 → 实现），文末给出与官方实现的差异、验证命令、小结与延伸阅读。
- 前置要求：一年以上 Vue 3 使用经验（组合式 API 顺手），不要求读过编译原理或框架源码。术语在首次出现处给出中英对照与定义。

## 配套工程

本系列全部代码样本来自配套的 mini-vue 工程（TypeScript + pnpm monorepo，约 8500 行源码、全套行为测试）。本仓库内直接运行：

```bash
pnpm install
pnpm test          # 每篇的行为断言都在其中
pnpm dev:showcase # 模板编译驱动的展示页（自研内核渲染）
pnpm build         # 参考官方脚手架的构建流水线（05 篇）
```

文中引用的代码均标注仓库路径（如 `packages/reactivity/src/effect.ts`），可对照阅读完整实现；行为断言可回溯到官方文档或 vuejs/core 源码。

## 内容依据

- 官方文档（cn.vuejs.org）：术语与对外行为的基准；
- [vuejs/core](https://github.com/vuejs/core) 源码（v3.5.x）：实现真相，「与官方实现的差异」各节均经源码核对；
- 《Vue.js 设计与实现》（霍春阳著）：组织方法参照（问题 → 权衡 → 实现 → 分析的行文结构）。
