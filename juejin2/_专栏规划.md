# 专栏规划 v3：「实现 Vue 3 内核」（juejin2，推倒重写版）

> v3 取代 v2（六篇论文体）。修订动因：v2 行文密度过高、概念不从例子长出来，读者反馈「根本读不懂」。v3 全面转向《Vue.js 设计与实现》的教学范式：**一章一个主题、例子先行、朴素版逐步演进**。

## 1. 定位与读者

- 跟随本仓库（mini-vue，全套行为测试护航）重写 Vue 3 内核：响应式 → 渲染器 → 编译器 → 补全与交付。
- 读者：会写 Vue 3（组合式 API 顺手），想弄清 `state.count = 1` 到 DOM 更新之间每一行代码的人。不需要编译原理或 Proxy 基础。
- 产出预期：读完能独立复述每个子系统的机制，并具备从零写出最小版本的能力。

## 2. 内容基准（三源，按优先级）

1. **官方文档（cn.vuejs.org）**：术语与对外行为基准。分篇对应：00–01《深入响应式系统》《渲染机制》；03《响应式 API：核心》；05–08《渲染机制》；09–11《渲染机制》（编译/补丁标记/静态提升/区块）；12《Transition》《KeepAlive》《表单输入绑定》。
2. **vuejs/core 源码（v3.5.x，本地 `third_party/vue-core`）**：实现真相。「与官方实现的差距」各节必须核对源码后落笔并给出路径。
3. **《Vue.js 设计与实现》（霍春阳）**：行文范式与教学序列的参照（见 §3）；内容不照抄，代码一律取本仓库实现。

## 3. 文风规范（v3 核心，逐条过检）

**叙述范式（源自书的实测行文分析）**

1. **章首路线图导语**：正文第一段交代「我们将做什么」，并用疑问句排比预告全章问题。例：「在这个过程中，我们会遇到各种问题：如何避免无限递归？为什么需要嵌套的副作用函数？」
2. **例子先行**：任何概念先给 5–20 行可运行的最小代码（手写、逐行中文注释），代码之后按「首先我们创建了……接着定义了……」顺序走读，最后给验证方式。禁止先抛抽象定义再找例子。
3. **朴素版 → 指出局限 → 演进**：仓库实现作为演进的终点引入。引入前先手写一个明显不够用的朴素版，明确说出「但很明显，我们还做不到 X，因为 Y」，再展开仓库实现如何解决。每章至少一组这样的演进。
4. **短段落 + 设问推进**：段落不超过 5 句、一段只推进一件事；单句尽量不超过 60 字，破折号插入语拆成独立句。每节至少一处自问自答（「为什么……？因为……」）。节末用「下一节我们将……」显式衔接。
5. **语言质感**：允许具象比喻（桶、账本、哨兵、锚点）与自然口吻；术语第一次出现仍给精确限定（例：「Proxy，ES2015 引入的元编程能力，Vue 3 用它实现响应式」），但定义独立成句，不塞进破折号里。

**禁止清单**（防回到 v1 的「AI 味」，注意边界：禁的是空洞套路，不是自然口吻）

- emoji、营销腔标题、空洞收尾（「以上就是本章内容」）。
- 通篇第二人称「你」轰炸（个别处允许）、连续反问轰炸读者（「你有没有想过……」式设问）；书的自问自答是**作者推演**，不是冲读者喊话，这是两者的分界。
- 一段塞多个论点、术语内嵌定义、80 字以上长句。

**章末骨架（固定五节，轻快笔法）**

1. `## 本章小结`：本章机制串讲，5 句以内。
2. `## 仓库文件索引`：本章涉及的源码文件清单（路径 + 一句话职责）。
3. `## 与官方实现的差距`：保留 v2 已核验的差异事实，改用轻快笔法；新增差异必须先对照 `third_party/vue-core` 源码。
4. `## 动手验证`：可执行命令 + 预期结果（测试命令或最小示例）。
5. `## 延伸阅读`：官方文档链接、core 源码路径、对应书章节号。

**完整性优先于篇幅**（v3.1 修订）：不设行数上限。凡对理解必要的代码不省略（「从略/略」只允许用于与当前论点无关的段落）；多步过程必须逐步推演（给出中间状态），不一句话带过；抽象机制配可运行的微观例子。篇幅以讲透为准（通常每章 300–600 行），绝不为行数牺牲完整性。

**事实纪律（不变）**

- 引用代码前必须打开仓库源码核对，标注仓库路径；节选注明。
- 行为断言可回溯（文档页 / core 源码 / 本仓库测试）；不确定的推断显式标注或删除。

## 5. 协作流程

```
写作（单章成稿，遵守 §3；定调篇 00/01 由主笔先写，其余分批并行）
  → 事实校对（代码引用逐处对源码；抽查 ≥3 断言回官方文档/core）
  → 文风校对（对照 §3 逐条：章首导语/朴素版演进/段落句长/设问/章末骨架）
  → 主笔终审（每批通读，跨章一致性：术语、衔接语、未讲先用的概念）
  → 人工终审 → 发布（站点随 push 自动部署）
```
