# 实现 Vue 3 内核 · 系列导读

> 本系列跟随一个从零实现的 mini-vue 工程，逐个子系统地重写 Vue 3 的内核。写法上向《Vue.js 设计与实现》看齐：一章只讲一个主题，每个概念都从能运行的小例子出发，先写朴素版、指出它做不到什么，再看完整实现如何演进过去。

## 读法建议

- **按顺序读**。00–08 是最小闭环（架构 → 响应式 → 渲染器 → 组件），09 之后进入编译器与工程化；每章开头的「路线图」会预告本章问题，结尾衔接下一篇。
- 前置要求：会写 Vue 3（组合式 API 顺手）即可，不需要编译原理或 Proxy 基础；术语在首次出现处给定义。
- 每章结构一致：正文（例子 → 朴素版 → 演进）→ 本章小结 → 仓库文件索引 → 与官方实现的差距 → 动手验证 → 延伸阅读。

## 配套工程

全部代码样本来自配套的 mini-vue 工程（TypeScript + pnpm monorepo，约 8500 行源码、全套行为测试）。本仓库内直接运行：

```bash
pnpm install
pnpm test          # 每章的行为断言都在其中
pnpm dev:showcase  # 模板编译驱动的展示页（自研内核渲染）
pnpm build         # 参考官方脚手架的构建流水线（第 13 章）
```

文中引用的代码均标注仓库路径（如 `packages/reactivity/src/effect.ts`），可对照阅读完整实现。

- 《Vue.js 设计与实现》（霍春阳著）：行文范式与教学序列参照（不抄内容，代码一律取本仓库实现）。
